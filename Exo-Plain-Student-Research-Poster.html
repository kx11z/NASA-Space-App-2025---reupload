ExoPlain: An Interactive, Explainable AI Platform for Exoplanet Discovery

An accessible workflow that connects exoplanet measurements with rapid, plain-language AI explanations.

Planet Pioneers · Student research team · NASA Space Apps Challenge 2025
Research question

How might an interactive AI tool help students explore exoplanet evidence without confusing an AI-generated explanation with a scientific confirmation?

1Why this project?

Exoplanet discovery draws on complex signals: a planet passing in front of a star can produce a small, repeating dip in the star's measured brightness. The data are fascinating, but the parameters and classification process can be difficult for new learners to interpret.

Goal: build an approachable learning experience that connects candidate measurements to plain-language explanations and interactive exploration.

The design challenge: make the science easier to explore without presenting an unvalidated AI guess as a discovery.

3Data & methods

  • Web prototype: Next.js / TypeScript interface for orbital, transit, planetary, stellar, and observational inputs.
  • AI explanation: the server sends submitted measurements to Gemini and requests a structured answer with important features.
  • Light-curve experiments: the Python project includes preprocessing and multiple model experiments (including CNN, LSTM, random-forest, and MLP approaches).
  • Sequence input: the training scripts use 2,048-point light-curve inputs; one training path uses an 80/20 train-validation split and augmentation.

4What the prototype demonstrates

The codebase brings together a space-themed interface, a 3D example-planet explorer, structured candidate-data entry, a Gemini-powered explanation route, and optional FITS upload UI.

Its central contribution at this stage is an educational interaction design: moving from measurements to a readable explanation, while showing where a learner should ask further questions.

5Current findings

  • Built: an interactive web prototype with data-entry, example exploration, and AI-explanation components.
  • Explored: several Python machine-learning architectures and preprocessing workflows for light-curve classification.
  • Not established: the available project materials do not provide an independently reproducible, held-out accuracy evaluation for the complete user-facing system.
Interpretation: this is a prototype and model-development project—not evidence that Exo-Plain can confirm planets or outperform expert review.

6Limitations & next steps

  • Confidence is not calibrated: the Gemini response is converted to fixed 85% / 15% confidence in the current API code.
  • Fallbacks can be simulated: FITS analysis may return randomized demo features when the Python service is unavailable.
  • Need a rigorous benchmark: verify labels and provenance, prevent target leakage with a documented split, then report accuracy, precision, recall, F1, and a confusion matrix.
  • Improve scientific safeguards: separate candidate triage from confirmation, cite the source data, expose uncertainty, and test explanations with students and astronomy mentors.
Take-home message
AI can make exoplanet data more approachable, while trustworthy science still requires verified labels, reproducible evaluation, calibrated uncertainty, and human expertise.
