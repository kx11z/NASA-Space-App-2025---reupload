# Historical files

These files are retained for reference and are not part of the GitHub Pages build.

- predictor-v1: Earlier nested predictor application.
- education-prototype: Earlier education website.
- static-prototype: Earlier standalone HTML website.
- web-styles: Unused earlier global stylesheet; the active stylesheet is apps/web/src/app/globals.css.
- deployment: Docker, Render, shell deployment files, and the superseded GitHub workflow from the former server setup. Their relative paths describe the original layout and are not supported entrypoints.
- package-managers: Historical pnpm lockfile and the former empty root npm lockfile. Use npm in apps/web.
- poster-build: Intermediate poster build artifacts and validation output.

Do not copy these projects into the active app. The maintained source is apps/web.
